# Literature benchmarks

The Rane and literature reports compare the published hybrid against reported external results and matched local calculations. The JSON files record the data and model fingerprints and detailed results. The reports explain sample differences and why the comparisons are not independent holdout tests.

Run `npm run research:rane-benchmark -- research/benchmarks/rane-benchmark-results.json` and `npm run research:literature-benchmark -- research/benchmarks/literature-benchmark-results.json` to regenerate the results.
