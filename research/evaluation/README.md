# Model evaluation

This directory contains the acceptance protocol and recorded evaluation results for the state-space model. `regenerate.sh` runs the recorded evaluation suite against the current data; its 2016 onward outputs are second looks, not untouched holdouts. See [evaluation](../../docs/evaluation.md), [metrics](../../docs/metrics.md), and [hybrid](../../docs/hybrid.md) for interpretation and limitations.

The `backbone/` directory records the prior Elo benchmark selection protocol and era-transfer evidence.
